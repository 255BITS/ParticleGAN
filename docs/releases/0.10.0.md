# ParticleGAN 0.10.0 release preparation

Status: draft release. The public trainer default remains optimized BISPF.

This release broadens and deepens what passing Forge means: a candidate must
fit the target distribution accurately, remain correct during continued
training and recover after target changes wherever those tasks are declared.
Reaching every mode alone does not establish convergence.

Review the generated [technique inventory](../../reports/forge/technique-inventory.md),
[test-by-test problems](../../reports/forge/problems.md) and
[0.10 policy](../../reports/forge/convergence-policy-010/README.md).
There is one current generated leaderboard; these notes link to it rather than
publishing a competing ranking. The expanded set has 106 view requirements
across 27 distinct tests. Selected BISPF evidence projects to 81/106, and no
selected recipe passes every expanded requirement.

The previous view revisions, numerical task gates, budgets, priors, sampling
laws, scientific outcomes and qualification packets are preserved. An old
qualification does not grant a pass under the expanded policy. This release
preparation launches no new scientific experiments or seed comparisons.
The README's separate actual-training illustration and its 20k failure retain
their original particle-cloud recipe, source, budget and sampling identity.

Runtime compatibility follows 0.9.0: optimized BISPF remains the default;
explicit recipes and supported saved checkpoints retain their contracts.
No new convergence or natural-image quality claim accompanies the version bump.

CI runs for pushes and PR targets on `develop` or `master`; manual test runs now
follow the same branch scope. Superseded PR runs cancel automatically, while
branch runs and immutable-source release checks remain independent.

Before publication, review this PR, finish the final source's CI/package checks,
date the changelog and record the exact release source SHA. Publish through the
[trusted release workflow](../releasing.md), using its tested distributions.
The current package version is prepared as 0.10.0; no release tag or PyPI
publication is created by this PR.
