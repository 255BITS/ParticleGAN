# Animation world model

A toy dream-loop experiment on the lunar three-generator pattern
(`lib/gym_transition.py`). One MoG1024 latent draw produces a state, its
successor and a frame; an encoder maps a state back into the latent so the model
can animate itself:

```
train:   z -> (G1 -> st, G2 -> st+1, G3 -> gt)          gt = frame of st
         E(st) -> z -> G1/G2/G3                           (particle_ae routing)
critics: D_state(st), D_state(st+1), D_image(gt), D_joint(st, st+1, gt)
sample:  st -> E -> z -> (G3 -> gt, G2 -> st+1) -> E -> ... ; animation = g1..gn
```

Training is strictly one-step; no trajectory is unrolled. st and st+1 are tied
by three one-step signals: the joint critic, the real-pair encoding loss
G2(E(st)) ≈ st+1, and composed samples G(E(G1(z))) scored by the same critics.
The dream loop is only the sampling/evaluation procedure.

## Data

`lib/sprite_animation.py` simulates a ball in a unit box (gravity 4, restitution
0.8, dt 1/30) that spins at a fixed rate. State is `[x, y, vx, vy, sin φ, cos φ]`;
frames are 32×32 renders with a dark notch that shows φ. Dynamics are exact and
deterministic, so every dream is scored against the simulator from the same
start. Frames are rendered from states, never stored.

| Split | Episodes × steps | Start height | Start speed | Notes |
|---|---|---|---|---|
| train | 2000 × 80 | 0.2–0.6 | 0–1 | never reaches y ≥ 0.75 |
| validation / test | 200 × 80 | 0.2–0.6 | 0–1 | same distribution |
| ood_test | 200 × 80 | 0.75–0.9 | 1.2–1.6, upward | ceiling bounces unseen in training |

## Losses

- RpGAN + b_cap on four critic roles; fakes are half prior samples, half composed.
- Real encoding: G(E(st)) vs (st, st+1, render(st)), averaged per part.
- Synthetic reconstruction: G(E(G1(z))) vs G(z), with G1(z) detached at E's input
  (the unapplied fix from the lunar readout's encoder-collapse diagnosis).
- Prior spread regularizer from the recipe; lr 1e-3 for every row (the recipe's
  4.25e-3 diverged with convolutional critics).
