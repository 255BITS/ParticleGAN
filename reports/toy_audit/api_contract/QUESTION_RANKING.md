# All retained toy questions, sorted by definition quality

**114 questions: 7 at 5/5, 46 at 4/5, 57 at 3/5, 3 at 2/5, and PR231 without an assigned historical score.** Every question has public-API execution, numerical gates and actual-observation goal media. The frozen campaign has 176 variants and 176 GIFs; the four later standalone questions add five GIFs, for 181 in total.

The 109 historical scores are the unchanged follow-up definition ratings. The four later PR233–236 scores assess their explicitly bounded questions. These scores measure how useful and well defined the question is; they do not rate a model’s convergence or assign a new score to a narrowed API variant. Historical weak questions now have stricter runnable variants, and useful negative controls remain.

The goal column describes the observable API variant rather than claiming an original broader application was solved. Open each GIF or the [detailed variant leaderboard](LEADERBOARD.md) for the declared bounds and scope. Shared variants and exact aliases are not independent confirmations. PR233 qualifies structural code retention only; its learned benefit has no frozen gate. PR234 is a zero-update mechanism test. PR235 and PR236 have bounded synthetic passes and separate failed real-task transfer gates.
