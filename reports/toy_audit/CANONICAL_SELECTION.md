# Canonical toy selection and retained controls

The default audit list folds **12 same-law entries** into five proved groups,
leaving **97 canonical problem entries**. All **109 named cases** remain
available with a specific scientific keep/control reason in
[the manifest](canonical-selection.json). No source definition, runner, gate or
immutable evidence is deleted. **No merged source deletion is justified.**

This is conservative inventory cleanup. It does not establish 97 independently
verified data laws or families, change selection weights, or authorize training
receipt reuse. Uncompared cases stay separate. The original ratings, statuses,
names and media links are preserved; a shared target is not an identical
effective training protocol.

Current definition assessments remain separately recorded in
[improvements.json](improvements.json). In particular, the mean-only critic and
uniform-output generator are now **4/5 analytic negative units**; their original
**2/5** ratings are archival fields, and their expected learned failures remain
separate from proof/control success. The active retained-case names use these
narrow negative-unit contracts.

## Listing and validation

```sh
python -m benchmarks.toy_audit.canonical_selection
python -m benchmarks.toy_audit.canonical_selection cases
python -m benchmarks.toy_audit.canonical_selection --json
python -m benchmarks.toy_audit.canonical_selection cases --id pr58 --json
```

The first command lists canonical entries; `cases` exposes every retained name,
role and reason. Invalid IDs fail. The loader also rejects missing/duplicate
IDs, conflicting aliases, unequal-law merges, stale catalog or source bindings,
and unregistered changes to the reviewed law proofs. Dynamic scale-law
fingerprints include update budget because it sets the target ramp; static
ring horizons remain separate host controls.

Focused tests cover rejection cases, retention of all original evidence,
actual source template bytes, dynamic target timing, source drift and a
standalone CLI that never imports Torch. They launch no training.
