# 0.5.0 release validation

No new benchmark training or seed sweep was run for this release. Existing
experiment results and original trainers were preserved. Public API tests cover
hard forward values and selected-center gradients, local Gaussian noise and RNG
isolation, exact enumeration of the categorical score estimator, Gaussian ELBO
dimensions, constant KL, absence of a KL reconstruction penalty, recipe
roundtrips, encoder optimizer deduplication and input validation.

Local Python 3.12 environment:

- Full CPU suite: 276 passed, 22 subtests passed; 4 opt-in CUDA cases skipped.
- Wheel and source archive built; `twine check --strict` passed both artifacts.
- Installed wheel outside checkout: all three recipes completed a reconstruction
  step on CPU; all three passed CUDA gradient smoke checks.
- All 4 real-data CUDA resume integration cases passed in 18.89 seconds.
  The suite uses the existing main-worktree
  CIFAR dataset. Its first invocation stopped at data lookup because the feature
  worktree has no local data directory; no model failure occurred in that attempt.

Validation logs are easy to tail at `/tmp/particlegan-050-validation/` on the
release machine. CI additionally checks CPU Python 3.10, 3.11 and 3.12 and
runs the installed-wheel example. Publication reuses the checked distributions
from the release workflow; the publishing job does not rebuild them.
