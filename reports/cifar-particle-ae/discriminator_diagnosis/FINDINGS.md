# D-only findings

The frozen feature representation is not obviously incapable of separating this generator from CIFAR. At the CNN E-only10k checkpoint, held-out AUC is0.5255. Holding G/prior fixed and continuing only the existing D for2048 steps improves AUC to0.9194 with the original regularization. Test/train scores0.9194/0.9202 agree. Pixel branch AUC rises0.5394→0.8896; combined pretrained feature heads0.4954→0.8762. These scores describe the components learned jointly, not independently trained branch ablations.

At the original50k checkpoint, held-out AUC0.4588 and image gradient0.0534 (vs0.3531 at10k), G adversarial gradient0.0575 (vs0.3735) and prior gradient0.00139 (vs0.01017). There is weak and somewhat inverted ranking on these live-weight draws. This supports unreliable D feedback in the joint trajectory, not a proof that it alone causes FID. FID measurements use EMA, while these probes use live G/D/prior.

Current-regularization D-only adaptation raises G gradient0.3735→11.1698 and prior gradient0.01017→0.12587. Larger gradients alone are not evidence of better generation; a joint FID test is necessary. A frozen-target discriminator has an easier learning problem than joint training.

Current coefficient1 every step reaches0.9471/0.9446, input gradient1.0744, G gradient13.1588. Training times47.7s/159.5s respectively vs48.6s forcurrent. Equal nominal average regularization does not produce equal optimization trajectories.

Bcap is one-sided above cap1. At both original checkpoint probes, no sampled real/fake total input norms exceed1: the penalty is locally inactive there. This does not establish inactivity throughout training. After2048 D-only updates, cap exceeds on real/fake12.2%/5.8% forcurrent and97.8%/97.3% forweaker. These are post-update fixed-panel diagnostics; lazy arms are measured immediately after regularized steps. Periodic within-cycle shocks remain a possible mechanism.

Pixel/features image-gradient cosine is approximately0 at both original checkpoints and small positive afteradaptation, not strong opposition. Total norm/sum of component norms stays0.74–0.78. This is ordinary nonaligned vector addition and does not support severe pixel/feature cancellation as the main explanation; parameter-gradient conflicts between objectives were not measured here.

Decision: jointly continue unchanged control, weaker coefficient (no D warmup), and current-reg D warmup (original coefficient thereafter). Warmup tests whether a one-time discriminator head start persists; coefficient tests sustained regularization relief. Use the same original10k parent and training RNG. No backbone replacement, fresh-head classifier, or encoder/prior intervention is needed before this test because the existing branches already recover separation. Every-step remains a possible later FID intervention, deferred because it costs more and weaker coefficient learns at least as much separation in this diagnostic.

Limitations:2048 held-out real images and2048 generated draws per evaluation, fixed across arms; no seed sweep. Train split diagnostic can include examples encountered in training. No test images are trained on. Parent G/prior is fixed during D-only, so D-only FID cannot improve. Full source/parent hashes, frozen state, nonmutating probes, and D Adam counters verified. Early failed exact replay test lacked deterministic-algorithm enforcement; with deterministic kernels and fixed pooling in the test only, original/new full-state continuation is bitwise equal. Production keeps historical CUDA settings.
