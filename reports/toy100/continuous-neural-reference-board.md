# Neural fitting references — outside the GAN candidate ranking

Updated September 24, 2026. **No production replacement is qualified.** We have a neural toy candidate that acquires all eight modes, holds its own solution, and repairs a measured error. We do not yet have a cheap, distribution-faithful solution on the production hosts. This is more progress than “only bank tests,” but less than a deployable fix.

Rank acquisition first, then sustained quality and recovery. Record runtime and changes to the objective separately: a coverage objective passing a toy is not a pure repair of the GAN game. A finite dip followed by measured recovery is different from lasting collapse. Original strict gate failures remain failures; the practical comparison does not rewrite their receipts. Whole-distribution shifts are outside this promotion requirement.

**Neural host is not the same as a GAN learning rule.** The anchor and likelihood corrections fit separate data objectives and can override native G motion. In particular, the likelihood target does not use the discriminator; running D and Adam around it does not make that replacement adversarial. Their success is a useful neural feasibility result, not proof that the original game has been stabilized. PR84 remains the leading reference if retaining GAN-driven learning is required. The conditional trajectory test also uses the unchanged PR84 path, not the two-dimensional likelihood/anchor correction.
