# Gradient-normalized discriminator: bounded scratch result

The tested gradient-normalized discriminator **failed the first frozen older-host gate** under both predeclared recipe cores. It did not advance to residual_student, mode_hold, the other older hosts, or any 100-Gaussian problem. The saved episodes remain deliberately ineligible for the production common-22 gate.

[Wu et al., *Gradient Normalization for Generative Adversarial Networks*](https://arxiv.org/html/2109.02235v2) propose replacing each scalar critic logit with `f(x) / (||∇ₓf(x)||₂ + |f(x)|)` (eq. 11) and differentiating through the gradient-norm denominator (eq. 13). This probe used the same map, with only `torch.finfo(dtype).eps` added to avoid undefined zero over zero. It normalized with respect to the generated/real **data** argument, not a conditional label, left the denominator attached in both D and G updates, and set `reg_arm="f_none"`, `reg_coeff=0`, `reg_kappa=0`. All other shared optimizer, prior, noise, resource, seed, and gate fields stayed as in the incumbent or the fresh 19/19 simpler core. Thus it tested a replacement for the explicit discriminator gradient-penalty coefficient and cap, not an output-bandwidth replacement.

The paper's gradient-bound Theorem 6 assumes a piecewise-linear underlying critic. Several frozen critics use Fourier features or smooth activation functions, and the existing Rp logistic game differs from the paper's selected hinge/non-saturating settings. The formulation here is empirical; no global 1-Lipschitz or theorem-backed convergence claim follows.

The six-row manifest was frozen before fitting at source commit `9dae27a432a6d69b6e58180f875be95bb845ebef`, SHA-256 `f9b004962878da5301bb2f32f1fa07c3b051980661f75ce2c656bd4973692402`. Two cores were staged in the fixed order trajectory → residual_student → mode_hold, stopping each core at its first strict failure. One CPU thread, AVX2 pins, fixed seed and full host budgets were used. The local ignored artifact path `artifacts/toy100-accuracy/gradient-normalization-v1-9dae27a/` contains the manifest, exact configs, complete trajectory curves, production source archive, separate GN executable source archive, application receipts, and byte-retention hashes.

For comparison, the incumbent's original 0.029/noise and gradient-penalty trajectory run scored identity MSE about 0.007315. The GN trials altered the logit map **and** removed the old penalty, so these results do not isolate the individual contribution of either change. The normalized denominator stayed positive and finite in both trials. Focused derivative tests passed for a linear critic, a conditional data argument, generator-through-critic gradient flow, no-grad evaluation, the zero/zero numerical case, and unsupported batch-coupled critic rejection. The linear test specifically distinguishes the paper's attached denominator from a detached shortcut.

Independent scratch regrading after artifact relocation reproduced both numerical FAIL verdicts. The ordinary production gate returned **INVALID** on both saved episodes. Removing `scratch_gn_receipt.json`, corrupting the separate GN source archive, or stripping only the protocol scratch marker was rejected; the saved config also carries an unsupported scratch selector, so a protocol-only stamp edit cannot make the evidence look like an ordinary candidate. The predeclared source/config and application receipt are checked before the scratch regrader reconstructs the ordinary frozen metric evaluation in a temporary copy.

Broader integration was deliberately stopped. The frozen `vector_unequal_mass` host uses `BatchDistanceDiscriminator`, whose score for one row depends on every row via pairwise features. The cheap `grad(sum(scores), batch)` is **not** the per-row derivative in the paper's formula. A fixed-seed 128×2 audit found maximum absolute difference **8.324**; on one CPU thread the exact diagonal took about **0.211 s** for one score batch versus **0.0013 s** for the incorrect summed shortcut, before differentiating through the denominator. The [audit script](gn_batch_coupling_audit.py) and saved result at the local ignored path `artifacts/toy100-accuracy/gradient-normalization-v1-9dae27a/batch_coupling_audit.json` pin the critic source and seed. An exact per-sample Jacobian adapter would be a major cost for a frozen full-budget host, and the initial trajectory failures give no evidence to justify adding that path. No target-aware or approximate batch-critic exception was introduced.
