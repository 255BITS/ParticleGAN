# Constant wave 3: C7/C8/C9 source and evidence audit

C7 has a measured stationary retention failure. C8 and C9 did not reach the ring quality gate within their recorded windows; those finite nonarrivals do not establish that eventual acquisition is impossible. C9 also failed its own unchanged image gate, independently blocking a default recommendation under that gate. No source-conformance blocker was found for the submitted unconditional ring/image hosts. Broader component API coverage remains incomplete.

This audit read immutable source ZIPs, completed metrics and regression/replay receipts, and checkpoint tensor storage with a restricted stdlib unpickler. It did not import Torch, run models, tests, training, or GPU work. `constant-wave3-audit.json` contains source hashes, rate statistics, raw checkpoint findings and replay receipts. `audit_constant_wave3.py` records the read-only procedure and image archival procedure; its archive destination is intentionally required to be new.

## Substantive numerical deltas

C7 uses the previously audited full-proposal secant resolver and explicitly fresh accepted critic reference. That source audit remains in `API-C7.md`. C8 changes only package recipe validation/dispatch and adds `local_game.py`; C9 changes only that new module plus recipe validation/dispatch. `game_update.py`, KA2, K3P and the native optimizer kernels remain byte-identical across C7/C8/C9.

Let `u` be the native joint D/G/prior displacement evaluated at the base state, including the normal Adam, guard and sparse A2 behavior. C8 and C9 restart `eta=1` on every accepted update and try binary halvings, with at most 16 backtracks. Each trial estimates `v=F(x+eta*u)` with the same batches/random draws and original optimizer history. They require `||v-u|| / ||u|| <= .5` before accepting. No radius persists between updates.

C8 uses the local estimate `(v-u)/eta` in the existing fitted dissipative/rotational-plane resolver. That is a substantive change from C7's full-displacement estimate, but remains a fitted low-dimensional response rather than a general implicit GAN solve. The locality check validates the derivative probe, not the full accepted resolver displacement: C8 does not enforce that acceptance stays within the probe radius.

C9 replaces that fitted-plane acceptance with `delta=eta*v`. Its locality check gives `||delta-eta*u|| <= .5*eta*||u||` and positive alignment with the native proposal, without guaranteeing nonlinear GAN acquisition or long-run stability. This is more than renaming a rate schedule: the field is evaluated at a displaced state. It is also adaptive numerical damping. It should be described as **constant nominal optimizer rates with variable accepted displacement**, not fixed-size updates.

Every recorded G/D LR is .00425 and prior LR .0085. C8 ring probe fractions range from 1/256 to 1/32; C9 from 1/512 to 1/16. Both median fractions are 1/128. All recorded accepted locality ratios satisfy the declared .5 condition. C8 uses 7–10 and C9 6–11 native joint field evaluations per public update. Last-500 mean accepted G/D/prior L2 movements are respectively (.0018887, .0016814, .0174483) for C8 and (.0017317, .0020188, .0064571) for C9. These costs and displacements should accompany nominal-rate claims.

## Native clocks, same-oracle replay and accepted state

The immutable `local_game.py:34–104` performs the declared transaction. It resolves a caller-supplied generator-real callable once, snapshots the trainer, and evaluates the base field. Before every trial, `rewind` restores optimizer moments, sparse A2 histories, critic controller/reference through optimizer state, G/prior EMA, module buffers, accepted count, private streams and global CPU/CUDA RNG. Real tensors and the once-resolved generator-real batch are reused. `JointStage.before/after` evaluates both player gradients at the same joint trial point and computes native displacements from the base parameters, avoiding sequential D-then-G contamination.

After acceptance it installs the accepted parameters, reloads **base-field** optimizer/controller history, restores the reference and copies the accepted critic once after activation, and recomputes G/prior EMA from the pre-update EMA and accepted parameters. The final trial supplies RNG and module-buffer continuation; earlier trial continuations are discarded. No hidden backtrack count or radius is checkpointed. Buffers at the final probe are not reevaluated at the accepted parameters, which matters when documenting custom stateful modules.

Raw checkpoint storage confirms both native Adam clocks are exactly 4600 in C7/C8/C9 ring finals and 7500 in C7 stationary, with ordinary scalar Adam step tensors still on CPU. Accepted counts, critic calls and observed steps agree. Ring references are byte-identical to all 9 accepted critic state tensors, with 3801 reference updates after 4600 accepted updates and no skips/reseeds. All per-step controller receipts agree with that accounting. The image clocks are exactly 600, with zero reference updates because the first blended call is 800; unequal D/reference tensors there are expected and not a reference defect.

Existing fresh-process continuation receipts for C7, C8 and C9 all match the complete expected 1800-update receipt after resuming at 1600, including models, native optimizer state, streams, global RNG and external real stream. These were read, not rerun. Existing regression logs report C7 36, C8 43 and C9 108 passing tests. C9's frozen tests retain meaningful assertions for sparse untouched prior rows, identical sampled indices across probes, one accepted optimizer/controller clock, exact accepted fresh reference, caller callback once, checkpoint continuation and horizon independence. No weakening of the C7 hook regression was found; its original failure and fixture correction are documented in `API-C7.md`.

`GANTrainer.step` keeps all stages, higher-order gradient construction and backward inside its serial-backward context. Checkpoints validate that mode and the exact recipe before mutation. C7's long/short evaluator-prefix receipt covers 2400 identical updates; C8/C9's existing CPU tests cover budgets 2 versus 10000 and stepping beyond the shorter nominal budget. Source inspection finds no evaluator horizon, target-change time, quality score or oracle target entering local acceptance. The shared fixed 360/720 input/output-noise startup and 799 pure-A calls remain declared learner startup behavior.

## Public integration limits that need explicit handling

1. **The complete method currently lives in `GANTrainer.step`.** `Recipe.make_optimizers` creates native optimizers but does not install local game transactions. A custom loop that merely sets `game_update='local_extragradient'` and calls those optimizers gets a different algorithm. An API port must invoke a public transaction component or extend the trainer; copying the flag is insufficient.
2. **The trainer explicitly supports one unconditional scalar GAN, exact `ParticlePrior`, and no encoder.** It rejects conditional/MoG/encoder recipes and has no auxiliary-loss or multi-critic transaction contract. Its staged parameter sets are fixed to D and G+prior. Faithful broader custom hosts require extensions that preserve their actual conditionals/auxiliary terms and include every optimized role in rewind/acceptance. The existing conditional penalty component alone does not solve that transaction gap.
3. **Optimizer hooks observe native staged calls, not accepted public updates.** Ordinary `opt.step()` still has one hook boundary, retaining the C7 fix. C8/C9 deliberately call each optimizer once per field evaluation, so external step hooks run 7–10 or 6–11 times per ring update respectively; optimizer state-load hooks can also repeat during rewind. Python side effects and caller-owned state are not rolled back. These submitted hosts register no such hooks, so this does not invalidate their results. A once-per-accepted-update callback must be a separate trainer-level contract, and arbitrary mutating hooks cannot be assumed replay-safe.
4. **Checkpoint/rollback coverage has a defined boundary.** Model tensors, optimizer/controller state and managed PyTorch streams are covered; arbitrary Python module attributes, external generators and callback side effects are not. The generator-real callback executes before the snapshot. Stateful or stochastic extensions need explicit state ownership and fixed-draw replay, rather than an unconditional claim that any user module is transactional.

These are concrete public API scope gaps and contract limits, not new quality rejections. C7's stationary departures and C9's frozen image failure are the measured default blockers. C8's observed ring nonarrival and heavy damping/cost remain bounded evidence for the refill review.
