# First arrival, settling and later instability

The shared evaluation declaration requires first arrival, every later departure,
passing/total observations, minimum quality and the retrospective final suffix.
It assigns the complete decision to supervisor assessment across all evidence.
It does not require that the first isolated threshold crossing instantly become
perfect forever. The user explicitly defines recovery as reaching the changed
distribution and becoming stable, without the former all81 deadline.

Keep the observation thresholds, evaluation budgets, change times, seeds and raw
scores unchanged. Keep original automated screen labels as recorded. A final
suffix alone never qualifies a candidate. Additional unchanged-candidate tests
can resolve whether early settling transients were followed by durable stability.
