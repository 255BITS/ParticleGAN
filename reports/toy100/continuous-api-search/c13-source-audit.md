## Numerical mechanism and transaction

C13 solves the actual implicit equation δ=F(base+δ), with fixed macrostep 1, at most 16 joint field evaluations, and Anderson history of at most six residual differences. It evaluates each proposed nonlinear field before judging its residual; this differs from a fixed three-field linear fit. `ProbeStage` inherits the full `JointStage.before/after` ordering: gradients are calculated at the probe parameters, each optimizer's update origin is then restored to the base parameters, and the probe critic is restored for the generator gradient. Thus subtracting base returns F(base+δ), not δ+F(base+δ).

The .5 per-role residual bound applies only when `converged` is true. Both image executions used 8,752 joint fields (mean 14.5867, range 2–16); only 99/600 steps converged, while 501 accepted the declared smallest measured total-residual fallback. Earlier trials were selected 453 times. Selected residual ratios reached D 22.2723, G 11.2437 and prior 12.2332. All raw trials, selections and applied displacements are retained. Constant nominal rates (.00425 G/D, .0085 prior) do not imply a constant applied displacement or an exact implicit solve.

Each field rewinds the optimizers, critic memory, EMA, model buffers, completed count, managed streams and CPU/CUDA RNG. Native moments, sparse latent history and critic counters are committed from exactly one base-gradient field. The accepted critic reference is updated from accepted parameters once after the pure-A prefix; G/prior EMA are rebuilt from the accepted parameters. Image checkpoints have native Adam scalar clocks 600 on CPU, controller calls/observations 600, and no anchor updates yet because first blend is 800. ## Source findings and repair

Original C13 kept the last trial's buffers and RNG when an earlier displacement won. This was a concrete generalized public API blocker for stateful modules or parameter-dependent draw paths. This image fixture has no model buffers and fixed draw counts, so its measured score remains valid. R1 changes only `particlegan/nonlinear_game.py`: it captures and explicitly commits one base field of model buffers and managed/global RNG together with the base-gradient native history. The accepted reference/EMA use accepted parameters and those base-field buffers. This fixes rejected-trial state leakage under the newly explicit ownership contract, without changing the solver arithmetic.

Original wording incorrectly called `game_stats` checkpointed. It is logged diagnostic state; no solver history survives a call. The preserved original declaration has a separate clarification, and R1 documents this accurately. Both versions' finite predicate checks displacement/residual entries but does not explicitly require nonzero displacement or finite scalar sum-of-squares, despite the declaration saying finite nonzero iterate. No zero role displacement or numerical error occurred in either image run; this is a contract edge, not an observed quality failure.

The existing immutable R1 regression receipt reports 117 passing tests in 32.60 s. All 28 source entries match its declaration and its package matches R1. The added test forces earlier selection followed by a nonfinite rejected probe and checks base-field buffers/RNG, finite committed parameters and one accepted history. Other tests cover same-oracle sparse samples, native histories, fresh-reference replay, horizon independence and hook refusal. These tests were read, not rerun.

## Public API and evaluator isolation

The real public `GANTrainer.step` dispatch owns the transaction and encloses all higher-order backward work in its serial execution context. Checkpoint loading checks that execution mode before mutation. Global/local optimizer step and serialization hooks are refused before the callback/snapshot, so repeated numerical probes cannot replay those external side effects; ordinary optimizer-step behavior remains separate. A supplied generator-real callback is resolved once. Conditional, encoder, auxiliary-loss and multi-critic hosts remain outside this trainer's declared support; those integrations have not been approximated or qualified.

The immutable recipe constructor ignores evaluator budget/schedule arguments. Continuous LR scales are 1, fixed startup noise 360/720 counts use accepted calls, and target/scorer feedback never enters the solver. The literal recipe total_steps7000 is inert for continuous updates.
