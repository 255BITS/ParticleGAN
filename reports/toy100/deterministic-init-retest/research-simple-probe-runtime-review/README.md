# Original simple-probe runtime audit

Run `python3 reports/toy100/deterministic-init-retest/research-simple-probe-runtime-review/audit_completed.py` from the research checkout. It scans only the declared eleven-case output root and writes per-case audits plus `pending-archive-index.json`; root applies those archive commands serially. It never edits the shared results or learner sources. A single artifact can also be checked with `runtime_audit.py --source DIR --queue-row ID --output FILE`.

The standard-library audit binds full source seals and original candidate authority, independent CPU proof, actual initialized CUDA parameters/buffers and raw initial optimizer copies, runtime/backend/streams,17 exact constructor random draws, all2400 scheduling actions and ordinary Adam calls, and the strict all8/HQ.9 final-five gate across24 observations.

These original probes do not save final checkpoints, native step clocks or final shared cursors. Their absence is explicitly reported; no state continuation or replay is claimed. The tested cosine/noise schedule uses the finite1200-update host horizon, so a quality pass would still not demonstrate horizon-free eligibility.
