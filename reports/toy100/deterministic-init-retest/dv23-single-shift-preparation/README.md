The run must match an independent CPU constructor proof for every non-RNG checkpoint value and named parameter/buffer before the first update. It also checks the original ring training/evaluation streams and global RNG hashes. No old weights are loaded.

The source reuses the reviewed released-K3P ring wrapper for measurement/checkpoint bookkeeping and replaces only the package/recipe binding and required initialization proof, recording controller diagnostics and preserving its autonomous rates. Native lazy Adam scalar clocks must remain CPU at first/final update; no eager injection, relocation or repair.

The complete 2400-update learner is copied for a frozen control, with main learner/global RNG equality asserted before the target moves. All460 observations, every failed observation after arrival, changes from passing to failing, acquisition/retention, shifted recovery, complete learning-rate/controller traces, initial/change/final checkpoints and source hashes are retained.
