# Preserve observed support across incomplete minibatches

The fixed-target [missing-batch replay](continuous-evidence/round6-sample-group-memory/input-result.json.gz) shows a structural failure of current-bank-only anchors: when a native-sized real bank contains no samples from one previously covered ring component, MST infers seven groups and one output MM target removes that mode. The conditional event probability for one specified component is `(7/8)^128 = 3.776e-8` per independent bank. Absence in one minibatch is not evidence that the target distribution removed the component.

The [proposed data-only memory](sample_group_memory.py) retains each inferred group's exact real-sample sum and count. A current MST group is matched to its nearest cached centroid only within half the smallest cached inter-centroid distance. Matched sums/counts accumulate, unmatched groups append, and absent cached groups remain bitwise unchanged. There is no configured group count, target-center access, model-state criterion, gain or learning-rate clock. The running mean improves the sampled-data estimate; it does **not** shrink the generator correction or its nominal Adam rate. The sums/counts must be serialized and restored with the learner; resetting them at a warm/hold boundary would invalidate this test.

The bounded [two-bank free-output filter](sample_group_memory_filter.py) reuses the exact ordinary and conditioned real128 banks from that replay, with the same frozen quality draw:

| Bank order | Current MST groups | Cache after bank | Output result |
| --- | ---: | ---: | --- |
| Ordinary, then component absent | 8, then 7 | 8, then 8 | Absent cached centroid unchanged; MM target remains 8 modes/HQ 1.0. Current-bank-only target is 7 modes. |
| Component absent, then ordinary | 7, then 8 | 7, then 8 | One new group appended. From the seven-mode output, first frozen-field MM round is 7 modes/HQ .91577; second round is 8 modes/HQ 1.0. |

For the first sequence the matching radius is 1.12006, with seven matches and one cached group absent. For the reverse sequence it is 1.12746, with seven matches and one new group. A support exactly on cached centroids is a fixed point of the free-output MM map to double precision; the helper leaves the global PyTorch RNG untouched. The [raw receipt and hash manifest](continuous-evidence/round6-sample-group-memory/manifest.json) include the original conditioned replay and both source versions. No neural host, optimizer or data stream was advanced by this filter.

The association guarantee is conditional. With at least two cached groups separated by `s`, a present group's centroid error plus cached-centroid error must be below `s/2` for a correct match. An unseen group's current centroid must be farther than `s/2` from **every** cached centroid to be discovered. Incomplete cache can violate that condition even without noise: cached centers `{0, 4}` and an unseen center at `1` merge under radius `2`. A complete cache containing a closest true-center pair and per-bank centroid error below one-sixth of true separation gives the usual correct-match margin. Gaussian tails provide no deterministic all-time error bound, and MST can create spurious groups. Permanent memory also cannot infer that a target component has truly disappeared; that needs separate change evidence. The anchor objective still does not enforce mode weights or full distribution fidelity.
