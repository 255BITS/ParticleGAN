## Small case set

1. **Actual initial and reacted state.** Native construction produces the
   typed backend9 initial state. Directly load the authentic owner reaction
   checkpoint, validate its real scalar status/chart/family, JSON diagnostics,
   four copy-phase/novel/isolation balances, and bound hook provenance. All
   source fixture bytes remain unchanged.
2. **Complete cold checkpoint.** Save the public full trainer state, construct
   an independent identical host, load it, and compare full training state and
   served view. Charts, coordinate caches, moved-row references and ephemeral
   packets are absent after load. State returned to the caller is independent.
3. **Measured positive serving continuation.** Where the actual geometry
   lease is eligible, use the unchanged public sample API for one 17-row warm
   call; save/reload its cursor; compare the next 17-row call on warm/cold
   branches, forwarded row IDs, outputs, owned eval cursor and complete state.
   No scoring, quality cloud, lease fabrication, explicit EMA override, noise
   change, new seed or unexplained conditional acceptance is used. An actual
   veto is reported as such rather than forced positive.
4. **Two CPU updates total.** On the fresh within-budget toy state, run one
   matched next update on each continued/reloaded branch with the same saved
   128-row real batch and global/owned RNG bytes. Compare losses, every trainer
   state leaf, gradients/modes, serving dispatch and all cursors. No reaction
   should be due in this small continuation, avoiding duplicate plans.
5. **Atomic negative controls.** Mutate one property of an authentic9 state:
   old backend8; wrong trainer schema; non-int backend schema; missing policy;
   old or wrongly typed common multiplicity; wrong cutoff; missing mean map;
   wrong mean scalar/integer type; nonfinite scalar; future mean stamp;
   wrong actual-K alpha; sign/status contradiction; inconsistent mean moves.
   Require ValueError before changing model/table/optimizer/controller/tester,
   gradients/buffers/modes, RNG, serving view or warmed derived-cache identity.
   Final field names and exact cases are pinned before execution, with only
   meaningful independent inconsistencies. Owner type/control suites are not
   rerun wholesale.
