## One bounded control set

1. **Supported observer boundary.** One literal, CPU dirty eval module mutates
   registered buffer values, binding maps and persistent registration; recursive
   modes; existing gradient values and gradient objects (including None); CPU
   global randomness and the four trainer streams plus the reaction stream.
   The unguarded control must expose those effects. The actual production
   `neutral_observation` must restore exact objects, bindings, values, registration,
   modes and RNG bytes after normal return and an injected exception. Exercise
   the actual `capture_features` wrapper on the fresh fixture using this same
   module shape, without changing production models. Buffer `copy_` version
   increments alone must not falsely invalidate the semantic epoch. Arbitrary
   Python/external RNG, parameter writes and module-tree changes are outside this
   supported observation contract.

2. **Prepared packet draw/commit.** Bind `CopyPacket`, `epoch`, `preview_pairs`
   and `commit_packet` to the real owner helper. The owner trace identifies the
   one intended device draw, shared between FAST/EMA with each prior's own
   geometry and row IDs. Compare accepted packet coordinates to the actual
   committed coordinates; the commit consumes no RNG and does not call `_move`
   or regenerate jitter. Existing shape-exact parent optimizer rows/history are
   copied, sources/untouched rows and shared optimizer step remain unchanged,
   and the graph/cache updates occur once. Participation evidence is reset;
   parent optimizer/history bytes are not inherited certification.

3. **Reject before writes.** Using private copies of an already prepared valid
   fixture packet, exercise stale epoch (table/chart/lineage/model/bandwidth or
   reaction stream), consumed packet and malformed shape/type/bounds/inheritance
   cases. Snapshot all protected tables, optimizer/history, graph, chart cache,
   evidence and RNG before the attempted commit. A rejection must leave every
   protected byte unchanged. A consistently redigested malformed packet is
   needed to reach the prewrite shape checks; digest corruption alone is not
   sufficient. A nonfinite/None observation must veto without row writes.

4. **Ownership and shared budget.** Bind the owner sidecar's complete earlier
   copy child/parent, isolation child/parent, newborn child and newborn source
   seed IDs. The mean source/child pair IDs are unique, disjoint from each other
   and that complete reservation union, jointly supported and inside in both
   views with retained own cell/category and common real topology group.
   Preserve occupied-cell survivors. `ordinary_copy = mass + support + global
   + mean`; `ordinary = ordinary_copy + novel <= floor(Q*N)`; isolation retains
   its separate existing ledger. Zero residual budget/veto makes no preview draw.

5. **Actual hook ordering and final state.** The sidecar must show fixed witness
   before the odd-driven prefix; original actions and FAST refresh; mean preview
   against the post-prefix epoch; exact commit and second FAST refresh; complete
   moved union and row-local BD invalidations; one fresh final paired lease;
