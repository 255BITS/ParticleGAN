# Focused real-anchor new-latent birth proposal

## Diagnosis

Frozen RA4 improves count transport but its copy mechanism cannot supply an empty eligible cell. The earlier frozen mode diagnosis establishes this from saved clean/served tables and real targets: update1250 has no training row nearest mode8, and update2000 has no accepted training row or eligible parent for mode13. Real target masses remain positive. Other missing modes also have inside-parent supply zero. Existing feature-cell boundaries/support tests sometimes reject raw points near a mode, but zero observed support also occurs. The served EMA table has a different set of missing modes, so measuring live support alone is insufficient.

This proposal introduces a distinct new-latent birth. It targets the largest physical cell/group vacancies with no unused inside p>Q copy parent, uses an existing distinct row only as an optimization seed, and solves toward an observed even-fitted real feature representative. No oracle mode label or evaluator quantity enters the policy. The step is a numerically truncated least-norm Jacobian solve, limited by current prior RMS coordinate spread. Work is bounded at four cells and four linearizations per live/EMA model. Each new point must pass the unchanged original p>Q support law, fixed even-fit inside boundary, and requested cell membership for **both** live and averaged generators. A seed is never claimed as a supported copy parent.
