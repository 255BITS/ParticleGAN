# Conditional source-only alternative

The current dv12 controller does not use observe_pair's real/fake moment signal.
Existing count tests can miss shape differences within their fitted categories,
and the current anchor solver accepts support before requiring target progress.

The reserved design uses even-real local mean/covariance targets to improve at
most four already certified ordinary copy births. A summed standardized group
moment objective avoids cancellation of opposing local shifts. Noise stays under
its original law; the proposed target explicitly accounts for a current empirical
emitted-versus-clean contribution rather than filling the real variance with
clean anchors alone. Paired endpoints must improve the empirical objective and
pass unchanged support/inside/destination checks. All common count cutoffs,
inclusive 5% ordinary budget, source/child reservations, rare survival and
population rebase/reset rules remain required.

The key limitation is capacity: this proposal must be rejected if existing count
transport has no birth slots in the biased groups. Moment discrepancy is not new
action authority or proof of local equality. Local finite-sample/noise-model error
and learned-feature ambiguity remain unqualified. One predefined four-cell,
four-iteration current-chart diagnostic could reject these assumptions after the
final original RA9 grid verdict; root has not authorized or run it.

This directory contains design prose and source hashes only. No PT load,
Torch import, chart/model forward, RNG draw, optimizer/training step, emission,
CUDA operation, production edit, numerical result or quality claim was made.
