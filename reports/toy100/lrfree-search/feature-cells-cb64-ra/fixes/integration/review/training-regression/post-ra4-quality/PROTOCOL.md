No oracle mode label, benchmark threshold, resampled emission, optimizer update, CUDA context or seed/level sweep participates in proposal selection or acceptance.

2. Target cells with positive real mass/cell/group vacancies but no unused inside p>Q copy parent. The seed can be unsupported; this is explicitly a novel latent birth, never a copy from that row.
3. Use at most the existing REAL_ANCHORS=4 representative cells per reaction, stable largest-vacancy order. Make one paired deterministic low-rank Gauss-Newton proposal per cell, with at most POWER_PASSES=4 linearizations for each current/EMA model when serving averages are enabled. Limit each latent step by the current prior's RMS coordinate spread; there is no task-tuned learning rate. G/D weights and all optimizer/stream states remain untouched.
4. Accept only finite current/EMA proposals assigned to the requested cell, inside the unchanged even boundary and with unchanged p>Q support on the same frozen critic metric. Both must pass when serving averages are enabled. A successful proposal is a new latent birth. It does not require the seed itself to satisfy copy-parent eligibility and does not inherit a copy-jitter proof.
5. Put accepted births before residual global support copying. They spend only the existing global outside-excess/inside-deficit certificates and shared floor(Q*N) ordinary budget. Subtract gross earlier mass/local certificate use, reserve all earlier and birth child/source rows, obey supported cell/group vacancies and preserve every unflagged survivor. There are no extra count tests: K+2K+2 stays Q/(3K+2). Failed proposals add no actions.
6. Keep serving selection unchanged. Keep the existing serving decision. Each birth carries explicit separately proposed current/EMA latents toward the same observed real anchor and resets its new row optimizer/evidence state; it never calls the copy path with an ineligible seed. Compare actual raw output support as annotation only. No forced serving state or mode assignment is used.
