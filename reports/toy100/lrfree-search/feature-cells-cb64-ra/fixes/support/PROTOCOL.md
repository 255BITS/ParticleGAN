# Support score diagnosis

This private lane reproduces the archived support failures at their existing
seeds: geometry 20260929 and cost 90229. No new seeds, generator/critic training,
GPU contexts, controller oracle inputs, changes to Q=.05, calibration ranks,
the five percent action guard, or acceptance thresholds are authorized here.

The initial diagnostic compares the archived rank eight spherical score with
real-only directional cell spread and information outside its projection. It
fits every candidate metric on even real rows and reserves odd real rows for
the same empirical conformal p values and BH procedure. Scores are inspected
before proposing a source patch. Oracle labels are used only after scoring to
report false positives and recall, never to fit a metric or choose a row action.

Required original cases include folded N2048/d2 and d128, trained600 and frozen
critics; geometry N1024/4096 with the same frozen bundle; and highdim, nominal,
rare_hole cost fixtures at N1024/2048/4096/8192. Repeated latent dimensions with
identical captured critic features are checked for equivalence without changing
seeds. Additional malformed, constant, tiny, duplicate, anisotropic, and
discarded-coordinate unit fixtures may isolate a reproduced cause.

Sources are private under support/pkg. Proven performance artifacts, shared
candidate packages and all archived studies stay read only. A focused patch is
proposed only after deterministic fixed-fixture tests. GPU execution, if needed,
will be submitted to the root agent's serialized slot.
