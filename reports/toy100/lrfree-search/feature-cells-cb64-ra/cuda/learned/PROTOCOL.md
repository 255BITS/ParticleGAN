Earlier CPU study artifacts remain read only and carry no canonical CUDA verdict. No candidate, reference, controller, metric formula, real stream, seed, architecture or acceptance threshold changes are allowed.

The tested source and configs come from `feature-cells-config-20260929/validation/candidate-freeze.json`, whose per-file maps and the implementation READY byte map are verified during preparation. Four serial training runs are fixed: toy/E22, toy/CB64-RA, mnist/E22, mnist/CB64-RA. Each uses seed 314159, N1024, z128, batch128, exactly 2000 updates, and `serial_backward=True`. Initial generator/critic/prior hashes must equal each problem's previous GPU E22 receipt. A mismatch is an execution error.
