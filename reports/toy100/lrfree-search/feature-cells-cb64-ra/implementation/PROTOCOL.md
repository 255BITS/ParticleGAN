# CB64-RA training semantics, frozen before acceptance runs

The candidate is a separate exact-E22-copy package with an opt-in `birth_death_backend="feature_cells"`. The default `"knn"` still instantiates the original ParticleBirthDeath implementation, uses the original DV12 sampling path, and serializes the original Recipe fields. No reference or previous experiment artifact is changed. This directory records implementation/tests; configs live in ../configs.

## Frozen recipe and feature snapshot

Generic overrides start from the read-only overrides-E22.json and add backend="feature_cells", cells=64, metric_rank=8, chunk=256, parent_policy="real_anchor" under the `birth_death_` prefix. Four real-reference power iterations and four deterministic Lloyd passes, scale prior4, parent reservoir64 per cell, nearest4 real representatives, final rank cap16, Q=.05, jitter Gaussian std=.025/norm cap=.05 are fixed source constants. Effective cells=min(64,real_reference_rows); effective rank=min(8,active_feature_width,real_reference_rows-1), with no varying units producing rank0 and no action. At least6 particles are required. With fewer20 particles the floor(.05*N) ordinary budget is zero and one isolation flag exceeds the5% guard.

At every full real FIFO turnover, capture clean table, iid fake pool and real head features under one frozen G/D eval snapshot, G->D chunks<=256. Fit all metric, cell and radius state using even real rows only; odd real rows calibrate support and provide independent categorical real counts. No raw data/output geometry, task name, labels, support oracle or desired mode mass enters controller decisions. Raw FIFO remains stored by the inherited backend, O(N*outdim); chunked capture does not solve reservoir image storage. The toy/native/image acceptance harnesses are external.

The metric divides learned head features by even-real standard deviation, drops dead units at1e-8 of maximum spread, centers on even-real means, and estimates rank8 via four power/QR passes from the private controller stream. Codebook initialization is farthest-first, followed by four Lloyd passes and radial scales sqrt((SSE+4*g²)/(count+4)); floor1e-3*g, g median positive cell RMS. Actual even-real nearest-centroid representatives supply bounded real anchors. Fit and representative selection are O(N*K*r), not reference-by-reference distances.

## Support and real anchors

Score=min distance/real-cell scale. Full odd-half conformal p=(1+#null>=score)/(Mcal+1); Q=.05 BH over N rows; disable isolation flags when >5% exact learned real feature copies repeat. Isolate only0<flagged<=.05*N. Shared calibration/adaptive model/data streams do not justify an unconditional FDR guarantee. The p floor and approximate40 minimum discoveries remain and are diagnostic.

Eligible parents are unflagged rows with p>.05, excluding ordinary moved children. Group all eligible rows once into cells and retain at most64 uniformly sampled parents per cell using private random priorities. For each flagged row, query the64 actual real representatives restricted to cells with an eligible pool; take the nearest4. Anchor at the nearest actual real representative and compare at most4*64=256 supported candidate features against that anchor. Select uniformly within twice its nearest parent distance, capped at the16th parent distance. Report actual candidate IDs/masks and real reference anchor IDs for geometry review. This is a feature-parent rule, not E22's latent rule.

Isolation anchors can increase mass in a nearby rare component; parent support/provenance and aggregate deficits are different requirements. Do not claim global deficit matching for isolation. Missing/empty supported cells cannot be restored by cloning. Cell deficit/inaccessible mass and parent-cell allocation remain visible.

## Actual ordinary count transport

Replace E22 kNN/Beta/Levina/sequential excursion evidence entirely for this backend. Given the even-real-fitted partition, compare odd-real counts R_j (M rows) with iid sampled fake counts F_j (N rows). For every cell use the exact conditional two-sample hypergeometric test: conditional on total t=R_j+F_j, R_j has Hypergeom(M+N,t,M) under equal categorical probabilities; the two-sided p sums probabilities <=the observed probability. At mostK tests; Bonferroni .05/K. Conditional validity assumes independent categorical samples with a fixed partition and equal laws; adaptive/reused FIFO streams and repeated evaluations are not covered by a cumulative error guarantee.

Cells with certified F_j/N>R_j/M supply ordinary deaths; certified reverse imbalance supplies ordinary births. Per-cell count quotas=floor(N*absolute_frequency_difference), limited by available clean excess rows and supported deficit parents. Exclude isolation-flagged rows from ordinary moves. Execute up to min(total accessible death quota,total accessible birth quota,floor(.05*N)) pairs. Allocate integer quotas proportionally by largest remainders; choose uniform excess children and uniform bounded deficit-cell parents. No neural loss or oracle target is added. No sequential W/Beta law is applied to counts; inherited S/W/n are cleared every new snapshot and serve only compatibility/reset diagnostics.

Ordinary transport and isolation both execute and are separately counted. Ordinary budget<=5%N and isolation has its separate<=5% guard, so together they can move<=10%N. Ordinary cell quotas compare noisy emitted fake counts to real calibration counts; clean-center assignment may differ. This is an explicitly approximate categorical transport heuristic, not a Fisher-Rao or continuous-density estimator. K64 may merge more than64 native modes.

## Sampling and row mechanics

Training `_generate`, served live/EMA samples, fake-pool capture and birth jitter ALL use Gaussian latent std=.025, capped at Euclidean latent norm .05. This intentionally replaces DV12's adaptive bandwidth/half-neighbor clipping for the feature-cell config; DV12's other optimizer/LR mechanics stay active. The fake pool draws table rows iid with replacement and adds the current output sigma, so its configured latent/output noise law matches training/sample. G/D eval-mode BD snapshots still differ from training-mode stochastic layers/BatchNorm; no equivalence is claimed for such networks. No all-table DV12 sampling nearest-distance pass remains on this path.

Execute both move plans from one pre-move snapshot with parents disjoint from all moved children. Reuse original `_move`, overriding only bounded jitter: copy latent+delta, EMA latent+same delta, all row-shaped Adam/AMSGrad buffers, and KA2 latent history. Existing GANTrainer.step rebase/reset hooks update the stationarity tester and row evidence for moved rows, preserving serving swap/EMA mechanics. Recapture moved features in chunks, update cell IDs/counts, conservatively invalidate old/new affected cells, and clear inherited evidence on those rows. Full snapshots are rebuilt after every head/reservoir change at evaluation boundaries; no cached cell evidence carries into a new partition.

## Public API, checkpoint and tests

`particlegan.feature_cells.FeatureCellSnapshot.fit(real_features, *, generator, cells=64, rank=8, chunk=256)`; snapshot.transform, assign(features)->(ids,distance²), support(query_features)->(flags,p,scores), select_parents(query_features,flags,*,ordinary_children=None,generator,pvalues=None)->(child,parent,detail), cell_comparison(fake_features), ordinary_transport(...), cache_queries/refresh_rows. All tensors stay on their current device. `.work` records projection, initialization, rebuild, pair distances, parent budgets, count-test terms and retained storage; no toy/harness imports.

`FeatureCellBirthDeath` subclasses the unchanged base class for FIFO/_features/_move; supplies maybe_apply, bounded jitter, diagnostics and backend-specific checkpoint validation. Checkpoints version the backend/settings and preserve private stream, FIFO, sample shape, counters and snapshot serial; derived feature caches are deliberately discarded on load and rebuilt before use. Legacy/default Recipe.to_dict and checkpoint semantics stay byte-equivalent; switching backends across checkpoints is refused.

Meaningful integration tests cover exact conditional count p-values, real anchoring/candidate masks, ordinary transport execution, copy of latent/EMA/AMSGrad/A2 rows, stale cell invalidation, all-zero/tinyN/5%-guard/duplicate cases, malformed config/checkpoint rejection, old default compatibility and deterministic checkpoint continuation. Tests use one deterministic fixture seed and do not tune to acceptance results. Reviewers independently run frozen efficacy/scaling/native/nonlinear/image gates after READY. Runtime fixes, if any, are logged with updated hashes and revalidation scope.

## Cost and intrinsic limits

PCA and fixed cells cost O(N*h*r+N*K*r+N log N), plus O(N*d) jitter and model forwards. Exact categorical p-values enumerate O(K*N) hypergeometric terms in the worst case. Parent search O(M*K*r+M*4*64*r), grouping O(K*N+N log N); cache refresh O(N+M*K*r). Retained features/latents/candidate traces are linear in N; raw FIFO is O(N*outdim). Every N/B evaluation cadence gives fixed-budget amortized work except sorting logN. Candidate semantic quality, rare mass and highdim conformal power may fail; no K/rank/threshold tuning or new seeds is authorized by this freeze.
