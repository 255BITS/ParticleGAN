# Remembered-donor finite-GH9 wrapper: bounded pure-output check

The frozen wrapper in `forward_kl_gh9_remembered.py` calls the prior finite-GH9 operator unchanged. It searches remembered real points **only when that operator selects exact rest**. The first coordinate replacement that strictly lowers the same cumulative finite-GH9 cross-entropy is followed by one GH9 EM step. With no improving donor, the output remains exactly unchanged. The selected cloud is a pure-output proposal; no GAN, optimizer, or long training was run in this check.

The source-bound [result and source archive](continuous-evidence/round8-forward-kl-remembered-wrapper/result.json) records bitwise target and full-receipt parity with the frozen operator for the actual native cold-1 and warm-1324 banks. The no-oracle API returns the same target and an ephemeral GH9 rule; it excludes diagnostic quality fields. Global torch RNG was unchanged. In a synthetic fixed-target rest trap, the frozen operator rested at GH9 cost 728.736; the first remembered donor reduced it to 363.288 and one EM step to 180.120. A separate no-signal case searched all 128 candidates and rested exactly. Three focused tests pass.

This establishes a specific rest escape without changing the already observed non-rest path. It does not establish neural realization, long-run cost, coverage, or continuous-KL descent. The finite GH9 objective and source epoch are explicit in the [declaration](continuous-evidence/round8-forward-kl-remembered-wrapper/declaration.json); every archived file is hashed in the [manifest](continuous-evidence/round8-forward-kl-remembered-wrapper/manifest.json).
