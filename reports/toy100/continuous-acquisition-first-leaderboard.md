# Acquisition-first neural evidence on the pinned stationary toy profile

This compares **completed live neural training**, not free-output proposals or saved-state filters. The target distribution is fixed. “Full acquisition” means the original cold trajectory and ring gates pass with eight modes and HQ ≥ .9; it does not certify probability mass, within-mode shape, all hosts, or indefinite stability. All listed experiments use constant nominal G/D `.00425` and prior `.0085` rates unless the cited source says otherwise. Runtime values are measured single-CPU-thread episode times where an archived receipt supplies them; “unrecorded” is not a zero-cost estimate.

Other completed neural screens have narrower evidence. PR82 G `.25`/D `3` passes warm200 and trajectory but ends cold ring at **6/HQ `.89209`**; [independent audit](pr82-independent-audit.md). The PR84 hard-rest and common-stencil arms end ring at seven modes; the single-convolution rest repair ends at six; [round4 results](continuous-round4.md). The original post-native-start anchor and guarded rest variants pass warm and borrowed hold, but no cold gate was run for those exact epochs; [round6 history](continuous-round6.md). The two-bank fixed-support memory variant passes warm200, borrowed hold1200, and three actual conditioned update checks, but its separately tested incomplete bootstrap confirms seven groups and then rejects 22 clear missing-group samples, so cold acquisition was withheld; [round8 history](continuous-round8.md). None of these is silently promoted above an actual cold acquisition pass.

The prestart omission result is a **paired continuation**, not a hypothetical permanent collapse: the source-bound [ten-update report](round8-prestart-omission-recovery10.md) and [raw states/receipts](continuous-evidence/round8-prestart-omission-recovery10/manifest.json) preserve the original strict failures and the measured recovery. The rare-event conditioning changes only one D bank; after that both arms follow ordinary data with identical final RNG and generated host. It does not estimate how often such events occur in unconditioned 12,000-step training.

The finite-GH9 forward-KL cloud currently has successful pure-output screens and a first-target neural landing check only. No complete live GAN/Adam warm, cold, own-state hold, or production evaluation exists for it, so it is **unranked** here. Its added likelihood objective would also be a change in training objective, not a pure fix of the existing game dynamics.

The next practical question for the top completed neural method is an exact, source-bound long continuation from its own update-2400 state, scored every update. That test can measure whether it retains and repairs coverage over time; no finite run proves stability forever. Its current sample-derived objective also allows arbitrary surplus-particle mass and has not passed the production mass/shape or other-host gates.
