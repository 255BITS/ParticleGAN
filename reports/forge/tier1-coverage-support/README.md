# Source-bound Tier 1 coverage support

The coverage campaign keeps one complete existing recipe per trainer family and
measures every eligible test in a tier. Missing, failed and incompatible results
remain distinct. This support change launches no qualification experiments,
changes no numerical bounds and supplies no historical pass credit.

The ordinary clean/live learned-MoG tasks remain intact. Atlas and E22 have a
separate `tier1_policy_coverage` view with seven source-bound variants of the
same questions. Their genuine independent row controls require an explicit
particle-cloud exception and state-selected public serving, without additive
output noise. The original task hash, complete definition, numerical gates,
initialization, update allowance and public sources are retained in every card.
No host-specific numerical tuning or routed recipe substitutes for the family.

Four scoped policy questions are executable: scalar Gaussian acquisition,
direct two-pole movement/slope, ring16 acquisition and the clock/state property
audit. The unused-token shared/slot objective needs conditional routing; the AE
posterior needs a routed AE owner; the five-row joint-word objective needs a
complete joint owner and a separately scoped minimum-population contract.
These three remain explicit compatibility blockers for independent Atlas/E22.
A runnable named routed formulation would constitute separate technique
coverage and cannot fill their independent original cells.

The clean `clockfree_audit_measurement_v1` variant executes the original four
state comparisons and zero-dependency gate without declaring that a scheduled
recipe is clock-free. Known clock dependencies are a measured diagnostic FAIL;
the original eligibility audit keeps its BLOCKED semantics. Continuous-policy
horizon probes change the independent external execution cap because the public
Recipe correctly requires `total_steps=None`. Complete typed checkpoints retain
source-defined diagnostic sentinels while learned-state health remains strict.

Reusable lifecycle/health observation and the direct-table fixture are adapted
from [PR273 at 77b8d983](https://github.com/255BITS/ParticleGAN/pull/273/commits/77b8d983194b9c24c35c5dd3cd4371631be09ed2).
The declaration here admits both actual public family recipes; it imports no
research qualifications, C6 task constants or tuned family adaptations. A
necessary two-line AMSGrad synthetic-control state repair is also reused.

Prepare final source-bound declarations after support merges and before source
freeze:

```sh
python -c 'from pathlib import Path; from experiments.forge.tier1_policy import write_declarations; write_declarations(Path.cwd())'
```

Commit these cards before paid execution. `materialize(parent, root)` returns a
policy task, `clock_measurement(parent, root)` returns the scoped clean audit,
and `write_declarations(root)` writes all seven cards and their separate view.
Forge source snapshots include each original parent card. Physical source drift
blocks the affected variant at preflight instead of blocking unrelated views.

Export an already certified attempt without training or sampling:

```sh
python -m experiments.forge.tier1_media reports/forge/attempts/ATTEMPT \
  --output reports/forge/tier1-coverage/media/ATTEMPT
```

Gaussian/ring animations use only already-scored samples; word animations use
retained generated/reconstructed outputs; behavioral animations show actual
training metric curves against their exact bounds. Clock animations show actual
saved generator movement across branches and full-state parity. Fixed axes and
media receipts preserve numerical observation schedules, artifact hashes and
zero added updates/draws. Stdout, checkpoint/state proof and per-observation
arrays stay in the local Forge attempt archive; publish compact receipts and
actual-training GIFs. Queue/campaign logs remain available through Forge's
`logs --follow` command.
