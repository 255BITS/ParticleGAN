Actual recipe values are lr .012, critic multiplier 1.5, prior multiplier 2.5, SBNP prior regularization .01, smoothed DualNorm .001, no EMA serving and no output noise. The actual adversarial loss is **`non_saturating`**. `Recipe.make_loss` activates `SinkhornRelativisticLoss` only for `loss=relativistic`, so that paired adversarial loss is inactive here. Sinkhorn coupling is active inside the **critic penalty**, where it selects transport chords and measures the cooling residual. Legacy host optimizer values are inactive provenance, not the executed recipe. The run uses the public deterministic initializer and named seed-0 streams; no identity/zero fixture is substituted.

The selected BISPF endpoint learns acceptable component covariance shapes but allocates the wrong probabilities. It fails mass TV **.17521** and normalized SW distance **.21362**. Its full-component covariance error **.31381**, minimum eigen ratio **.32515** and HQ **.99561** all pass their unchanged endpoint bounds. Calling this endpoint an anisotropic-shape collapse would misidentify the observed failure.

The endpoint component counts are **1,284 / 2,083 / 729**, or **31.35% / 50.85% / 17.80%**, against equal thirds. The middle component's excess probability accounts for the total mass TV. The third component receives only **53.39% of its requested probability**. Component full covariance errors are **.23534 / .38455 / .32154**; all are small compared with the averaged .85 bound. Their core eigen ratios **.47893 / .91805 / .32515** clear .15.

This is also a temporal allocation failure: mass TV fails **all 24 scheduled checks**. The third component has zero assignments through update 200, appears with 182/4,096 draws at 250, and ends at 729. Shape improves substantially, but the output allocation does not reach its bound. Full-component covariance passes only three checks; the earlier trajectory has genuine spread/tail errors, so the endpoint finding must not be generalized to every earlier state.

The problem-list prose cites an earlier BISPF covariance error near 2.0 and TV near .191. Those numbers do not belong to this selected measurement. The [older BISPF report](../../bispf/README.md) retains its original source; the exact selected evidence in this report supersedes neither its result nor its identity.

In the frozen source, the critic penalty's Sinkhorn coupling uses a detached scalar median squared distance rather than per-component covariance whitening. Its finite-iteration coupling and endpoint/chord critic penalty therefore supply a plausible route for common geometric directions to dominate shared output motion. The readout does not contain per-component transport mass, critic force or parameter-step projections, so this remains a hypothesis. Fixed uniform MoG weights constrain latent row probabilities, not how many learned rows or kernels map into each target component.

SBNP's explicit local 2D circularization requires **latent dimension 2** and no references; this host has **latent dimension 4**. Its active-plane latent term may still apply, but it cannot simply be described as forcing three 2D target ellipses to become circular. Endpoint covariance/eigen gates already contradict that explanation as the immediate terminal bottleneck. The special harmonic lock cannot activate before call 1,650, outside the 1,200-update budget. The selected quintic convolution delta does not execute on this MLP architecture.
