# Exponential Moving Prototype Flow (`EMPF`)

`EMPF` (`critic_formulation="empf"`, `prior_regularizer="empf"`, `prior_reg=0.01`, preset `"empf"`) is a clock-free, constant-learning-rate ParticleGAN formulation inspired by *e-means* (Bessa et al., arXiv:2611.09501). It replaces noisy raw-minibatch transport targets with a persistent online sufficient-statistics prototype bank $(S, N)$ checkpointed inside the critic step record, with no EMA critic network copy (`ema_critic=None`, `reg_anchor_weight=0.0`) and no step-count schedules.

## Four Formulation Pillars

1. **Online `e-means` Sufficient-Statistics Prototype Bank ([`update_emeans_prototypes`](../../../particlegan/_empf/prototypes.py))**:
   Maintains unnormalized feature sums $S \in \mathbb{R}^{K \times d}$ and assignment counts $N \in \mathbb{R}_+^K$ ($K = \min(K_{\max}, B_r)$) with exact centroids $C_k = S_k / N_k$. Instead of dataset-size or epoch-horizon schedules, EMPF adapts the EMA rate from the per-batch cluster hit ratio plus normalized distribution-shift innovation and Poisson empty-cell starvation shocks:
   $$\alpha_{\mathrm{eff}}(K, B_r) = \operatorname{clip}\!\left(\alpha_0 \left(\frac{B_r}{K}\right)^\eta,\; \alpha_{\min},\; \alpha_{\max}\right)$$
   Stationary distributions remain at zero shock ($\alpha_{\mathrm{eff}} = \alpha_{\mathrm{base}}$), while abrupt support shifts accelerate dead-prototype turnover. Starved prototypes ($N_k < \tau_{\mathrm{rev}}\bar{N}$) revive deterministically via mass-conserving proportional splitting of the heaviest prototype ($S_{\mathrm{donor}}, N_{\mathrm{donor}} \to \frac{1}{2}$ each) along a low-discrepancy R2 perturbation direction, using zero RNG draws.
2. **Mass-Weighted Prototype-to-Fake Entropic Optimal Transport ([`mass_weighted_sinkhorn`](../../../particlegan/_empf/transport.py)) & Conditioned Fiber Pairing ([`empf_loss`](../../../particlegan/_empf/loss.py))**:
   Couples $C$ to detached generator samples $y = G(z)$ with non-uniform row marginals $w_k = N_k / \sum_j N_j$ and uniform column marginals $1/B_f$, preserving rare-mode mass instead of forcing uniform batch-to-batch row matching. Conditioned critic calls automatically bypass the marginal bank, align transport chords per conditioning fiber, and blend relativistic within-fiber pairing once conditional energy settles.
3. **State-Driven Settling Elastic Born-Infeld Critic Penalty & Zero-Mean Gauge ([`EMPFCriticPenalty`](../../../particlegan/_empf/penalty.py))**:
   Bounds critic input gradients on real endpoints, fake endpoints, and stratified prototype-to-fake Sinkhorn chords using the smooth Born-Infeld potential $\phi_{\beta_{\mathrm{eff}}}(\|g\| - \kappa)^2$ plus a harmonic floor and zero-mean logit gauge $\frac{\gamma_{\mathrm{gauge}}}{2}\bar{D}^2$. Far-from-manifold mode acquisition uses $\beta_0 = 6.0$ ($r_{\mathrm{ema}} \ge 0.16$) and tightens quadratically once transport residual settles ($s_{\mathrm{settle}} = \operatorname{clip}(1 - r_{\mathrm{ema}}/0.16, 0, 1)$, $\beta_{\mathrm{eff}} = \beta_0 + g_{\mathrm{cool}}(B_r)\,s_{\mathrm{settle}}^2$).
4. **Degree-of-Freedom-Aware EMPF Prior Regularizer ([`EMPFPriorRegularizer`](../../../particlegan/_empf/prior.py)), Floor-Subtracted Thermal Cooling ([`EMPFCriticAdam`](../../../particlegan/_empf/critic.py)), & Hybrid DualNorm Dense Polar Profile ([`DualNorm`](../../../particlegan/optim/dualnorm.py))**:
   Combines initial-moment tethering, scale-free $k$-NN log-repulsion, local scatter circularization, and a local median-normalized 1-NN revival tether for stranded prior particles while skipping global moment/covariance distortion on low-count discrete codebooks ($N \le \text{DoF}$, with a short-range one-sided prototype non-collision hinge on reference-anchored discrete codebooks). Instance-bound shock-filtered transport EMA (`EMPFStepRecord` schema 2), trimmed central-$[0.04, 0.96]$ 1D quantile-$W_2$ floor-subtracted $1/\sqrt{B}$ cooling with DualNorm step-scale damping, prototype-referenced 2D harmonic capture locks, and Sinkhorn-free discrete-simplex post-acquisition Chamfer cooling ($\mathrm{ema\_decay}=0.96$, smoothstep band $[0.064, 0.084] \to 0.0004 < \mathrm{optimizer\_smoothing}$) damp post-convergence noise while instant-reheating on distribution shifts. In `empf-v8`, DualNorm uses `optimizer_dense_profile="newton_schulz_hybrid_v1"` (exact SVD with rank cutoff on $\min(m,n) < 64$ or $\max(m,n) < 128$; guarded 32-iteration cubic Newton-Schulz on $\min(m,n) \ge 64$ and $\max(m,n) \ge 128$).
