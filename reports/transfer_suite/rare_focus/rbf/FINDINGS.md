# Local-feature architecture findings

**No rare-mode winner in eight declared local-feature critics.** The bounded screen stopped after eight episodes; none qualified for a six-data-toy followup. These results do not improve the supported formulation score.

The closest result is **128 trainable Gaussian features + Softplus(beta5)**, with 12,993 D parameters. At the original 256 particles, batch128 and 1,200 steps it achieves live HQ **98.804%**, mass TV **.08721**, covariance error **.47907**, minimum mass ratio **.77962**, and normalized sliced distance **.09910**. All final bounds pass except the minimum component eigenvalue ratio: **.131176 < .15**. No observation in this run passes every bound. Its generated rare-component mass is 1.880% against a target2%, so occupancy alone would conceal the remaining geometry failure.

The 64-feature Softplus5 card and 128-feature SiLU card also pass every final bound except the minimum eigenvalue ratio (.04481 and .00558 respectively). Adding a residual smooth head does not solve the issue: covariance error1.15241 and minimum eigenvalue ratio .00907 both fail despite HQ99.487% and mass TV .02290. The [matrix](MATRIX.md) includes all eight cards and parameter counts.

This is a distinct representation hypothesis from axis Fourier/activation tuning. Gaussian centers are initialized from a single seed0 standard-normal draw using an explicit local generator. Generic octave bandwidths are declared in the card. Depending on the card, centers and widths remain fixed or learn through only the existing discriminator loss. Positive trainable widths use `exp(log_width)` without a new objective or regularizer. Features contain raw coordinates and Gaussian responses, not target centers, labels, moments or data-derived frequencies. There is no normalization. The residual variant has two residual blocks with two affine layers per block; its full D has21,185 parameters. Other D counts range from6,465 to12,993; the original D has4,929. Capacity differences are explicit.

All nonarchitecture settings are identical to the original vector host: original G64×2/z4,256 particles,batch128,Adam(0,.99),G/D/prior LRs .001/.0015/.01,Rp logistic,b_cap coefficient3/kappa1.25,prior regularization .05,no particle L2,cosine and1:1 updates. Every episode has24 fixed live observations, unchanged behavioral thresholds and the original final-five stability requirement. EMA is retained separately. No seed sweeps, longer training, auxiliary losses, feature matching or covariance supervision were used.

Exactly **8 GAN episodes**, **192 live observations**, **75.793955 seconds** summed recorded wall time. Static checks separately confirm pointwise behavior, reproducible initialization, active cap backward, and finite gradients for learned centers/widths in all eight architectures.
