# Fast Lunar lander: full command evidence

The complete pipeline ran from an empty output directory in about **73 seconds**
on CPU. Its declared landing/speed gate passed on validation and then on a
separate, untouched test cohort. This is the bidirectional-main-thrust Box2D
variant, not stock LunarLander. A crash never counts as a fast landing.

| Learned controller | Validation landings | Validation success steps | Test landings | Test success steps |
| --- | ---: | ---: | ---: | ---: |
| Slow | 20/20 | 210.80 | 28/30 | 217.43 |
| Fast, selected round 1 | 20/20 | 184.40 | 29/30 | 186.45 |

On the **27 test worlds where both landed**, fast won **27/27**, with a
**1.180× ratio of mean flight times** (15.2% fewer steps) and **32 median steps
saved**. No test flight crashed or flew away. Two slow and one fast flight
settled with incomplete leg contact; these remain failures under the unchanged
strict success rule. This is a finite-cohort result, not a universal landing
guarantee. Validation, not test outcomes, selected
`fast_round_1.pt` from three candidates. The final checkpoint is `fast.pt`.

The compact evidence folder keeps the selected checkpoints and media. The
command's local output also contains every candidate checkpoint, transition
dataset, successful expert dataset, extracted same-reset pair dataset, source
snapshot, and structured log. Hashes in `report.json` identify these larger
  local datasets, which can be regenerated by the command.

This run uses clean source revision `1a4f347`, based on `develop` `3d08a3a`.
It trains dynamics on 31,671 expert transitions plus 5,472 exact-replay
simulator branches from world-training episodes only. Engine-power action
features preserve the ignition jump. Slow training uses 8,000 cloning plus
1,200 RpGAN updates; each fast round uses 8,000 plus 400. Every checkpoint and
flight uses **live weights, with EMA disabled**.

The previous test cohort `84000:84030` informed the failure investigation and
is now diagnostic. This corrected run declared `94000:94030` before training
and evaluated it only after validation selected and froze the winner.
[Historical audit records](audit/README.md) preserve the old result and the
fixed-data experiments. The corrected slow policy also lands all 92 original
successful expert training worlds. Longer, 2,400-step adversarial training
still drifts; this correction supports the documented bounded schedule.

Reproduce from the repository root:

```bash
uv run --extra lunar python -u examples/fast_lander.py --out results/gym/fast_lander
```

See the [guide](../../docs/fast-lander.md), [development rounds](../../docs/lunar-training-rounds.md),
and [consolidated PR map](../../docs/lunar-consolidation.md). The behavior-cloning
initialization is explicit; the final policy performs real RpGAN updates and
receives gradients through its frozen learned world model. This run establishes
the final controller's behavior, not an isolated benefit of RpGAN over cloning.

Validation on the corrected source: **724 passed, 5 skipped, 1 expected failure**,
plus 27 passing subtests. The expected failure is the legacy native toy already
recorded on `develop`. Four skips require opt-in CUDA data and one needs the
optional local `torch-fidelity` package. The complete command and separate
smoke export both completed.
